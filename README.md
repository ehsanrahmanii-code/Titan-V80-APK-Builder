# TAI — TITAN PRO V80 Android APK

این مخزن موتور کامل TITAN PRO V80 را به‌صورت APK اندروید خودکفا می‌سازد.

## دریافت APK

در GitHub به **Actions → Build TAI Android APK (TITAN PRO V80)** بروید و آخرین اجرای موفق را باز کنید. از بخش **Artifacts**، بسته **TAI-Android-APK** را دانلود و فایل **TAI.apk** را نصب کنید. فایل **TAI.apk.sha256** برای بررسی سلامت دانلود است.

## موارد داخل APK

- کل سورس ماژولار TITAN PRO V80، نه نسخهٔ نمایشی یا استاب.
- محیط اجرای Python 3.11 داخل برنامه.
- NumPy، pandas، Flask، requests، websocket-client، Waitress و وابستگی‌های ترانزیتی که Chaquopy در زمان build داخل APK بسته‌بندی می‌کند.
- رابط WebView داخلی با موتور Flask محلی روی 127.0.0.1:5000.
- ذخیره‌سازی پایدار در پوشهٔ JJJ داخل فضای خصوصی برنامه (بدون نیاز به مجوز All Files).
- حالت تحلیل‌محور؛ معاملات زنده به‌صورت پیش‌فرض غیرفعال‌اند.

ساخت برای دستگاه‌های ARM64 با Android 8.0 یا بالاتر انجام می‌شود. دادهٔ قیمت و بازار برای اسکن زنده به اینترنت نیاز دارد؛ کتابخانه‌های برنامه پس از نصب از اینترنت دانلود نمی‌شوند.

## اندازه

Workflow اندازهٔ APK را بررسی می‌کند و اگر از 40 MiB (41,943,040 بایت) کوچک‌تر باشد، ساخت را ناموفق اعلام می‌کند.
